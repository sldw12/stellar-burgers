# Stellar Burgers — проектная работа

Проект основан на стартовом наборе. Первый шаг (маршруты и модальные окна) сохранён; дополнительно подключены Redux Toolkit, API ингредиентов и заказов, конструктор, авторизация и профиль.

## Запуск

1. Установите зависимости: `npm ci`.
2. Скопируйте `.env.example` в `.env` (в архиве рабочий `.env` уже присутствует). Для публикации через Git `.env` игнорируется, поэтому создайте его локально.
3. Выполните `npm start`; для проверки сборки — `npm run build`.

Публичная лента и личная история опрашивают API раз в 10 секунд; кнопка «Обновить» обновляет ленту сразу. Для отправки на ревью перенесите изменения в ветку `review` своего репозитория и создайте Pull Request в `main`.
